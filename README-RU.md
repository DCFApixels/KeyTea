<p align="justify">
Небольшой менеджер паролей, который вычисляет пароли вместо их хранения на устройстве пользователя или сервере. Приложение работает на любом устройстве с совместимым браузером, а сохранённую копию Password Tea можно запускать без подключения к интернету.
</p>

## ❓ Как это работает?

<p align="justify">
Если коротко, Password Tea вычисляет пароли вместо их хранения. Из комбинации мастер-пароля и названия сайта генерируется уникальный пароль для этого сайта. Одинаковые входные данные всегда дают одинаковый результат, поэтому сгенерированные пароли не нужно сохранять. Мастер-пароль усиливается с помощью PBKDF2-HMAC-SHA-256 (600 000 итераций), а настройки генерации хешируются SHA3-512 перед преобразованием результата детерминированным алгоритмом приложения. Сгенерированный пароль нельзя напрямую преобразовать обратно в мастер-пароль, однако слабый мастер-пароль всё ещё можно подобрать перебором.
</p>

> **Совместимость:** добавление PBKDF2 изменяет все генерируемые пароли по сравнению с предыдущими версиями. Password Tea не переносит старые результаты генерации.

<br>

## 🔒 Безопасность

**Отсутствие хранения и передачи паролей третьим лицам обеспечивается следующими особенностями:**<br>
+ Приложение может работать без подключения к интернету;
+ Приложение не использует сторонние фреймворки; криптографические библиотеки [js-sha3](https://github.com/emn178/js-sha3) и [@noble/hashes](https://github.com/paulmillr/noble-hashes) включены прямо в исходный код;
+ Проект имеет открытый исходный код, поэтому пользователи могут изучить его и самостоятельно проверить поведение приложения.

**Преимущества:**<br>
+ Достаточно запомнить всего один мастер-пароль, а для каждого сайта генерируется отдельный пароль;
+ Генерируемые пароли детерминированы, но выглядят случайными, поэтому их трудно угадать;
+ Password Tea не хранит сгенерированные пароли, поэтому в приложении нет единого хранилища, компрометация которого раскрыла бы все пароли сразу;
+ Сгенерированный пароль можно быстро изменить: изменение даже одного входного символа создаёт новый пароль.

**Недостатки:**<br>
+ Утечка мастер-пароля открывает доступ ко всем сгенерированным паролям;
+ Один мастер-пароль легче подвергается различным видам атак.

**Локальные данные:**<br>
Password Tea сохраняет в `localStorage` только настройки генерации: названия ресурсов, имена пользователей, версии и наборы символов. Мастер-пароль и сгенерированные пароли туда не записываются. Как и у любого веб-приложения, это хранилище доступно коду, работающему на том же веб-адресе. Поэтому при использовании размещённой версии другое приложение на том же адресе теоретически может прочитать эти настройки, но не сами пароли.

Чтобы полностью исключить именно этот риск, скачайте Password Tea и запускайте его офлайн через отдельный локальный веб-сервер, не используемый другими приложениями. Например, выполните `python -m http.server 8765` в каталоге проекта и откройте `http://127.0.0.1:8765/`. Так Password Tea получит изолированное локальное хранилище. Это не заменяет защиту браузера и устройства от вредоносных программ и расширений.

## ⭐ Особенности

+ **Кроссплатформенность:**

<p align="justify">
Использование веб-технологий позволяет запускать приложение на любом устройстве с совместимым браузером. Его также можно встраивать в другие приложения.
</p>

+ **Настройка наборов символов:**

<p align="justify">
Некоторые сайты требуют наличия определённых символов или, наоборот, запрещают их. Точная настройка наборов символов позволяет генерировать пароли в соответствии с такими требованиями. В паролях можно использовать латинские буквы, цифры и спецсимволы, а также буквы других алфавитов. По умолчанию доступны наборы спецсимволов, цифр, латинских и кириллических букв.
</p>

+ **Перегенерация пароля с помощью версии:**

<p align="justify">
Если пароль необходимо сменить, в настройках можно увеличить его версию и получить новый пароль.
</p>

+ **Детерминированные вычисления:**

<p align="justify">
Одинаковые входные данные дают одинаковый пароль на любом поддерживаемом устройстве.
</p>

## 📜 Руководство

### Экран ввода мастер-пароля
На начальном экране пользователю предлагается ввести мастер-пароль, который используется для генерации паролей.

![image](https://github.com/user-attachments/assets/396df36d-1381-433c-9b66-44ca7cec2ce5)

После ввода мастер-пароля нажмите кнопку Continue, чтобы перейти к списку паролей.

![image](https://github.com/user-attachments/assets/5360397a-ba85-4855-9fc0-9f009c318080)

### Экран выбора пароля

В верхней части экрана отображается список ресурсов. Для получения пароля выберите нужный ресурс из списка.

Список ресурсов можно редактировать. Кнопка со значком плюса внизу списка добавляет новую запись, кнопка в виде шестерни открывает экран редактирования ресурса, а соседняя кнопка в виде корзины удаляет ресурс из списка.

![image](https://github.com/user-attachments/assets/58f01be4-b28a-4f08-9099-e9327588093f)

После выбора ресурса в расположенном снизу поле `password` появится сгенерированный для него пароль. Кнопка справа от поля копирует пароль в буфер обмена, а следующая кнопка показывает пароль, который по умолчанию скрыт.

![image](https://github.com/user-attachments/assets/08958b72-9549-4fdb-b105-482b9807af13)

В нижней части экрана расположены кнопки для импорта и экспорта данных пользователя. Эти функции позволяют переносить данные между устройствами.

![image](https://github.com/user-attachments/assets/d776ade5-f000-4ec4-b21f-0041d19a389f)

### Экран редактирования информации для пароля

Вверху доступны четыре поля для редактирования:
+ **Name** - название ресурса, для которого генерируется пароль; оно также отображается на экране выбора пароля.
+ **User** - идентификатор аккаунта, позволяющий получать разные пароли для нескольких аккаунтов на одном ресурсе.
+ **Length** - длина пароля.
+ **Version** - версия пароля. Нажатие кнопки `Up` увеличивает версию и генерирует новый пароль.

Ниже расположен список наборов символов, в котором можно выбрать наборы, используемые при генерации пароля.

Список наборов символов можно редактировать. Кнопка со значком плюса внизу списка добавляет новый пустой набор, кнопка в виде шестерни открывает экран его редактирования, а соседняя кнопка в виде корзины удаляет набор из списка.

![image](https://github.com/user-attachments/assets/538cf86a-47c9-4296-8290-6224c6f8af0a)

После завершения редактирования нажмите кнопку `Save` для сохранения изменений или `Cancel` для отмены.

![image](https://github.com/user-attachments/assets/efb2d3da-8c45-4468-b562-dbd89e055514)

### Экран редактирования набора символов
Для редактирования доступны три поля:
+ **Name** - отображаемое в приложении название набора. Никак не влияет на генерацию пароля.
+ **Charset** - набор символов в виде текста. После сохранения символы сортируются, а дубликаты удаляются.
+ **Priority** - приоритет набора. Он влияет на частоту, с которой символы этого набора встречаются в пароле, относительно приоритетов всех выбранных наборов. Чем выше приоритет, тем чаще используются символы набора. Независимо от приоритета, пароль содержит как минимум один символ из каждого выбранного набора.

![image](https://github.com/user-attachments/assets/b38c4022-d33d-44f8-b446-d7372f65616f)

После завершения редактирования нажмите кнопку `Save` для сохранения изменений или `Cancel` для отмены.

![image](https://github.com/user-attachments/assets/efb2d3da-8c45-4468-b562-dbd89e055514)
